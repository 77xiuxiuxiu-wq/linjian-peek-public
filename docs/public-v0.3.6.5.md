# 公开版 v0.3.6.5

本版是稳定性小修，重点降低公开后端请求压力，并减少无障碍服务与前台服务重复轮询。

## 修复内容

- 默认轮询从 1.5 秒调整为 3 秒；过低旧配置会自动回到 3 秒。
- 生活状态上传增加 10 秒限频，避免每轮轮询都上传状态。
- 无障碍服务只做兜底轮询：前台服务运行时不再重复请求 `/api/poll`。
- 无障碍兜底轮询间隔调整为约 12 秒，不影响前台服务正常收命令。
- 遇到 HTTP 429 时，手机端会短暂退避，MCP 侧会返回明确的限流说明。
- 无障碍异常提示补充受限设置、电池优化、后台运行权限的排查步骤。
- 保留 v0.3.6.4 的 MCP 超时、package_empty、门禁工具兼容修复。

版本号：`0.3.6.5` / `30605`。
固定签名保持不变。
