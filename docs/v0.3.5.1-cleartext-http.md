# v0.3.5.1 HTTP 明文连接修复版

本版基于 v0.3.5.0 归电公开版，修复 Android 端连接本地/局域网纯 HTTP 服务时报错的问题。

## 修复内容

- 在 `android/app/src/main/AndroidManifest.xml` 的 `<application>` 中启用：

```xml
android:usesCleartextTraffic="true"
```

- 允许连接类似下面的测试服务器地址：

```text
http://192.168.x.x:8513
http://局域网IP:端口
```

- 解决日志中反复出现的错误：

```text
Cleartext HTTP traffic to 192.168.x.x not permitted
```

## 使用提醒

- 手机和本地 server 需要在同一个局域网。
- 自建公网服务仍建议使用 HTTPS。
- 本版主要用于本人设备、本地调试和局域网测试，其他功能与 v0.3.5.0 保持一致。
