# v0.3.4.5 地址保存修复

本版修复 v0.3.4.2 中服务器地址被误判为旧地址后静默清空的问题。

## 修复内容

- 不再把 `zhangxinchuang-server-rork.onrender.com` 自动清空。
- 保存服务器地址时只清理首尾空格和末尾斜杠。
- 用户误填 `/health` 或 `/mcp` 时，会自动保存为基础服务器地址。
- 版本号更新为 `0.3.4.5`，便于确认是否安装到最新版。

## 用户填写示例

服务器地址可以填写：

```text
https://zhangxinchuang-server-rork.onrender.com
```

或项目实际部署的新地址。不要把整段 health 检测地址当作服务器根地址。
