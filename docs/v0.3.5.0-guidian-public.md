# v0.3.5.0 归电公开版

本版把私用版「归电」搬入公开版，并明确不合并聆音、鲸鸣、声息等私用能力。

## 新增内容

- 感官页新增「归电」卡片：展示归电开关、上次回来、下次最早归电、今日次数、拒绝理由和自动检查状态。
- 设置页新增「归电设置」：可改开关、远程调整许可、全屏来电、间隔、冷却、每日上限、安静时段、目标 App、主题、文案池和拒绝理由。
- 归电目标 App 支持 ChatGPT / Claude / Gemini / 自定义昵称 / Android 包名。
- 归电对象读取设置里的“对方称呼 / AI 名字”；文案池支持 `{AI}` 和 `{USER}` 占位符。
- 接受归电会记录已回来并跳转目标 App；拒绝归电会保存拒绝理由。
- MCP 增加 `get_guidian_state`、`set_guidian_config`、`trigger_guidian`、`mark_guidian_returned`，并新增轻量 `get_senses_state`。

## 隐私边界

归电只保存连接状态、时间戳、目标 App 前台状态和拒绝理由，不读取聊天内容，不截图，不合并私用声息/聆音/鲸鸣。
