# 公开版 v0.3.6.4

本版是公开版稳定性小修，重点处理真实用户环境里出现的 MCP 超时、App 参数为空和公开包清理问题；同时保留 v0.3.6.3 的守护日历保存修复与应用门禁旧版工具名兼容。

## 本次修复

- `get_phone_state` 改为快速读取服务器缓存状态，不再等待手机实时刷新；活动日志记录改为异步，不影响工具返回。
- MCP 到同步后端的请求支持更细的超时控制：普通请求、快速状态请求、活动日志、命令排队、命令状态轮询分别限时，避免平台报“单个工具超过 20 秒未返回”。
- `open_app` 参数为空时直接返回 `missing_app_target`，提示填写 App 名称或包名；不再把空命令下发到手机端造成 `package_empty`。
- 门禁/屏幕休息类工具在需要目标 App 时也会做空参数拦截，减少“看起来调用了但手机端不知道目标”的失败。
- MCP 侧新增常用 App 名称映射：小红书、抖音、微信、QQ、QQ音乐。用户只写中文名时也会尽量自动补全包名。
- `waitCommand` 的状态轮询改为短超时轮询；手机端未及时回传时会先返回排队状态，避免整条工具链卡死。
- 清理公开包里的 `server/.env` 和 `__pycache__`，只保留 `.env.example`，减少公开发布时的误解。

## 继承 v0.3.6.3 的修复

- 守护日历「添加日子」入口使用独立添加面板，保存后刷新守护页、陪伴页和生活状态层。
- 守护日历保存改为同步确认，兼容中文分组、农历、重复字段；相同标题 + 日期 + 日期类型会更新旧记录。
- `get_guardian_calendar` 返回 `upcoming`、`custom_events`、`events`，方便确认自定义纪念日。
- MCP 补齐 `get_lock_state`、`lock_app`、`unlock_app`、`extend_lock` 等应用门禁旧版兼容工具名。

## 保留内容

- 保留公开版固定签名，可覆盖安装上一版公开版。
- 保留 Render / MCP 自动公网 URL 与旧内网地址兜底逻辑。
- 保留无障碍权限状态延迟复查与受限设置提示。
- 保留守护日历、今日轨迹、目标 App 设置、息屏、MCP 工具和公开版自部署能力。
- 公开版不包含私人绑定接口或私人模块。
