# v0.3.4.4 旧服务器提示修复

本版解决公开用户误填旧 `zhangxinchuang-server-rork.onrender.com` 后不断报 `UnknownHostException` 的问题。

- 旧 rork 测试地址不再被静默清空，避免用户以为“地址保存不了”。
- 启动服务和截图测试前会检测旧 rork 地址。
- 检测到旧地址时，App 会停止启动并在日志/Toast 中明确提示：旧测试服务器已停用，请部署自己的 Render 服务后填写新的 `https://xxx.onrender.com` 地址。
- 后台看门狗和无障碍后台轮询不会再对旧 rork 地址反复请求，避免 UnknownHost 日志刷屏。

注意：App 端不能单独使用，必须配套一个可访问的服务器地址和对应 Token。
