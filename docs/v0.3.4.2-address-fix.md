# v0.3.4.5 地址保存修复

本版修复公开版 App 在卸载重装后仍可能恢复旧服务器地址的问题。

## 修复内容

- 禁用 Android 自动备份，避免旧 `SharedPreferences` 被系统恢复。
- 启动 App、前台服务、无障碍服务时自动清理旧默认地址 `zhangxinchuang-server-rork.onrender.com`。
- 前台轮询不再只吃启动瞬间传入的地址，会在每轮轮询前重新读取连接设置里的服务器地址。
- 日志改为显示“实际使用地址”，方便判断 App 当前到底连向哪里。

## 用户升级后怎么做

1. 安装 v0.3.4.5。
2. 打开设置 → 连接设置，重新填写新的服务器地址和 Token。
3. 启动服务。
4. 日志里应显示：`实际使用地址：你的新地址`。

如果日志里仍出现旧地址，说明安装的不是新版 APK。
