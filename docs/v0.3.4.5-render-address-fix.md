# v0.3.4.5 Render 地址误拦修复

本版修复 v0.3.4.4 对部分用户自建 Render 域名的误判问题。

- 不再把 `rork` 或 `zhangxinchuang-server-rork.onrender.com` 当作旧地址关键词拦截。
- 所有用户自建的 `https://xxx.onrender.com` 地址都允许保存和连接。
- 地址清理只负责去掉末尾 `/health`、`/api/poll`、`/api/state`、`/api/screenshot`、`/mcp` 等常见路径，不改变主域名。
- 如果连接失败，日志会按真实原因提示：DNS 解析失败、Render 冷启动超时、Token 不一致、接口不匹配或服务器内部错误。

用户排查顺序：

1. 浏览器打开 `https://你的服务名.onrender.com/health`。
2. 如果能打开，再确认 App 里的 Token 与 Render 环境变量一致。
3. 如果打不开，先查看 Render Logs，等待冷启动或重新部署。
