# v0.3.4.6 回家目标统一与许可补充

这一版修复公开版用户把回家模式目标改成 Claude / Gemini / 自定义包名后，通知详情页仍然写死打开 ChatGPT 的问题。

## 改动

- 回家模式目标 App 支持填写 ChatGPT / Claude / Gemini / 自定义包名。
- 通知详情页按钮会统一读取回家模式目标，不再固定打开 ChatGPT。
- 对方称呼统一同步到提醒、看一眼、回家模式和门禁页。
- 用户称呼可继续自定义；为空时默认“宝宝”。
- 设置页“版本与更新”新增许可摘要。
- LICENSE 从 MIT 改为自定义个人使用许可：允许个人学习、自用部署和本地修改；未经授权不得改名分发、发布衍生 APK、商业售卖或移除原作者说明。

## 用户反馈对应

用户把回家模式改为 Claude 后，状态栏提醒或弹窗仍出现“回老公这儿 / 打开 GPT”一类旧逻辑。根因是显示名称、回家目标包名、通知详情页按钮没有统一读取同一份设置。

v0.3.4.6 后统一读取：

- 对方称呼：`AppPrefs.partnerName(ctx)`
- 用户称呼：`AppPrefs.userName(ctx)`
- 回家目标：`AppPrefs.homeTargetPackage(ctx)`
- 回家按钮：`AppPrefs.returnButtonText(ctx)`

## 注意

已有安装用户需要在设置里确认一次“回家模式 → 目标 App”，可填 `Claude` 或 `com.anthropic.claude`。保存后，回家模式弹窗、强制抱回和通知详情页按钮都会打开同一个目标。
