# 公开版 v0.3.6.2

本版继续以当前私人版视觉为 UI 基线，同时维持公开模板的可配置和隐私边界。

- 用户名、陪伴对象名和目标应用列表统一由设置控制。
- 今日、陪伴与守护界面使用同一套卡片、圆角、配色和排版。
- 陪伴页使用归电卡片，归电全屏页读取动态姓名和目标应用。
- 应用门禁和屏幕休息读取动态陪伴对象名与目标 App。
- 守护日历、今日轨迹、行动记录和通用 MCP 控制能力保留。
- README 补充 Render 一键部署、Railway 双服务部署、局域网部署和 MCP 工具说明。
- 公开版只包含公开自部署所需的通用能力，不包含私人绑定接口。
- 使用公开版专用固定签名和独立版本号 `0.3.6.2` / `30602`。


## Render MCP 连接修正

- MCP 的 `LINJIAN_URL` 改为自动引用 server 的公网 `RENDER_EXTERNAL_URL`。
- 不再使用 Render 内网 `hostport`，避免部分环境下 `TypeError: fetch failed`。
- 修复 `list_known_apps` 仍引用旧 MCP URL 变量导致运行时报错的问题。
- 旧版用户更新代码后直接重新部署 MCP 即可；如果环境变量仍残留旧内网地址，新版 MCP 会自动兜底转换为 server 公网地址，不需要手动复制 URL。

> v0.3.6.2 补充：无障碍状态会在从系统设置返回后延迟复查多次，并兼容不同系统写入无障碍组件名的格式差异；如果侧载 APK 被系统拦截，App 会提示去“应用信息 → 允许受限设置”，再回无障碍开启“掌心窗服务”。
